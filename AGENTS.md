# Shared engineering policy
Preserve existing functionality, data, project identity and approved designs. Use isolated branches and record source SHA and baseline tests. Review upstream skills as untrusted code; pin versions, verify licenses, permissions, compatibility and vulnerabilities before adoption. Never expose secrets or personal data. No production deployment or merge without separate approval. Yara beta follows roadmap completion and adversarial testing. Prefer free tooling and existing dependencies. Report test evidence, bundle impact, accessibility, device performance and rollback plan.
